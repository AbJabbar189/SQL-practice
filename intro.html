SQL Version Standard Note: -- ============================================================================= /* Agarche SQL ek ANSI/ISO standard hai, lekin is ke alag alag versions hain (jaise MySQL, SQL Server, PostgreSQL, MS Access). Lekin tamam systems mein bunyadi commands bilkul ek jaisi hoti hain: SELECT, UPDATE, DELETE, INSERT, WHERE. */ -- ============================================================================= -- 3. Using SQL in Your Web Site (Website Mein SQL Ka Istemal): -- ============================================================================= /* Ek aisi website banane ke liye jo database se data dikhaye, aap ko 4 cheezon ki zaroorat hoti hai: 1. HTML / CSS (Website par data ko khubsurat tarike se dikhane ke liye). */ -- ============================================================================= -- 4. What is RDBMS? (Relational Database Management System): -- ============================================================================= /* RDBMS ka matlab hai Relational Database Management System. Tamam modern database systems (MS Access, MySQL, SQL Server, Oracle) RDBMS par mabni hain. RDBMS mein data TABLES ki shakal mein save hota hai. - Table: Related data ka aik majmua (collection). - Columns (Vertical): Attributes ya fields (e.g., CustomerID, Name, City). - Rows / Records (Horizontal): Har ek individual entry (e.g., ek specific customer ki poori maloomat). */ -- ============================================================================= -- Basic SQL Command Example: -- ============================================================================= -- Customers naam ke table se saara data nikalne ki query: SELECT * FROM Customers;
