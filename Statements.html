SQL Rules (Zaroori Baatein Yaad Rakhein): -- ============================================================================= -- Rule A: SQL Keywords Case Sensitive NAHI HOTE. -- Matlab: 'select' likhein ya 'SELECT', dono bilkul aik hi baat hain. -- Lekin acchi practice ye hai ke hum Keywords ko HAMESHA CAPITAL (UPPER-CASE) mein likhein. -- Rule B: Semicolon (;) Ka Istemal: -- SQL query ke aakhir mein Semicolon (;) lagana standard tarika hai. -- Is se database ko pata chalta hai ke ek query khatam ho gayi hai aur doosri shuru ho rahi hai. -- ============================================================================= -- 3. Sab Se Zaroori SQL Commands Ki List: -- ============================================================================= /* 1. SELECT -> Database se data nikalne / dekhne ke liye. 2. UPDATE -> Database mein mojood data ko tabdeel karne ke liye. 3. DELETE -> Database se data ko mitaane ke liye. 4. INSERT INTO -> Database mein naya data daalne ke liye. 5. CREATE DATABASE -> Naya Database banane ke liye. 6. ALTER DATABASE -> Database ki settings badalne ke liye. 7. CREATE TABLE -> Database mein naya Table banane ke liye. 8. ALTER TABLE -> Table ka structure (Columns) badalne ke liye. 9. DROP TABLE -> Poore Table ko mitaane (Delete karne) ke liye. 10. CREATE INDEX -> Tezi se search karne ke liye Index banane ke liye. 11. DROP INDEX -> Index ko khatam karne ke liye. */
